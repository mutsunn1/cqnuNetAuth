# 重庆师范大学校园网自动认证脚本

基于校园网 `GET /eportal/portal/login` 接口的简易自动认证工具。支持 Windows、macOS、Linux，使用 Python 3.9+，无需安装第三方依赖。

## 使用

先连接学校的 Wi-Fi 或有线网络，在项目目录执行：

```bash
python3 auth.py --init
python3 auth.py
```

Windows 可将 `python3` 替换为 `py -3`。初始化会询问账号和密码(**注意此密码为你的校园网密码而不是校园门户密码！**)，密码输入不显示，保存到脚本旁的 `config.json`。账号只填实际账号，程序自动添加 `,0,` 前缀，并正确编码密码中的特殊字符。

保持运行，每 5 分钟重新认证一次：

```bash
python3 auth.py --watch
```

可用 `--interval 60` 修改间隔（最少 30 秒），按 Ctrl+C 退出。此模式会定期发送认证请求，包括已经在线时；若服务器返回“请勿重复登录”，程序会提示“当前已认证，无需重复登录。”，并在下一周期继续尝试。它不会修改系统的开机启动配置。

也可以复制 `config.example.json` 为 `config.json` 后自行填写。默认根据到认证服务器的路由自动选择本机 IPv4；如果使用 VPN、多网卡，或认证页面显示的 IP 与自动检测不同，请在配置的 `user_ip` 中填写认证页面对应的 IPv4。

```bash
python3 auth.py --config /absolute/path/config.json
```

## 凭据与日志

需要检查服务器实际返回的字段和消息时，在校园网内执行：

```bash
python3 auth.py --show-response
```

此选项显示本次请求的 JSON/JSONP 响应内容（JSONP 外层会去掉），包括认证失败时的消息，并遮盖配置中的账号、密码及其 URL 编码形式。无法解析的响应不输出原文。默认关闭，不写入日志文件；分享输出前请检查其他个人信息。此选项不会改变认证结果的判断。

- 仓库只提供占位符，不包含任何真实账号、密码或抓包截图。
- `config.json`、`config.*.json`、`.env`、日志、抓包文件和截图被 `.gitignore` 排除。自定义配置文件名需自行加入忽略规则；不要强制提交本地配置。
- 配置在本机以明文保存；初始化在 macOS/Linux 上使用仅当前用户可读写的权限，Windows 上请使用受保护的个人目录。
- 脚本不会输出请求 URL，默认不显示服务器响应；`--show-response` 可显示遮盖已知凭据后的响应。禁用系统代理，并拒绝 HTTP 重定向。
- 校园网接口使用 HTTP GET，凭据会按该协议以明文随请求传输；URL 编码不是加密。请仅在可信的校园网环境使用。

## 接口与验证范围

默认认证地址为 `http://10.0.254.125:801/eportal/portal/login`，来源于浏览器中的认证请求。动态 IP 不写死，其他参数使用该请求的默认值。支持 JSON 和 `dr1005(...)` JSONP 响应：`msg` 或 `message` 字段包含“请勿重复登录”时判定为已认证，否则 `result` 为 `1` 或 `"1"` 时判定为本次认证成功。HTTP 200 本身不代表认证成功。

尚未在广泛地在学校网络实际验证。若学校更换认证接口或返回结构，需要相应调整脚本；默认不会打印原始响应以免泄露凭据。单次运行认证成功或已认证的退出码为 0，认证或配置失败为 1。

运行不访问真实校园网的单元测试：

```bash
python3 -m unittest discover -s tests -v
```
